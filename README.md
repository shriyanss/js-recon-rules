# js-recon-rules

[![Plumber Score](https://score.getplumber.io/github.com/js-recon/js-recon-rules.svg)](https://score.getplumber.io/github.com/js-recon/js-recon-rules)

This repository contains the rules for [`analyze` module](https://js-recon.io/docs/docs/modules/analyze) of [js-recon](https://github.com/js-recon/js-recon).

## Installation

JS Recon will automatically download the rules from this repository whenever the `analyze` module is run.
